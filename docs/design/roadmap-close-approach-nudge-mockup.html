Why two surfaces. The strip is the active catch at the actionable moment (dismissible so it can't nag); the tab-badge is the passive residue so dismissing doesn't lose the gap — the same graduated push→standing-cue pattern as a desktop banner that collapses to a menu-bar dot. Reuse, not invention: ◐ + warn-amber + the dashed-warn CONVENE? treatment are all already in the system (darcula-foundation §2 signaling language + roadmap-outcome-drillin's CONVENE? banner), so this reads as the roadmap's own signal surfaced proactively. Plain language (never "Epic #N" / "iteration not parent-ready" jargon) — names + the human gap ("designer-review open"). Trigger boundary (mechanism = dev's, #1703 readiness + the close-approach window): close-approach = current iteration within the close→open band; not-ready = NEXT fails a convene-check (#1703).
