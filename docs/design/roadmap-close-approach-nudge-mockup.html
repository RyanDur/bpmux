Why two surfaces. The strip is the active catch at the actionable moment (dismissible so it can't nag); the tab-badge is the passive residue so dismissing doesn't lose the gap — push→standing-cue, like a desktop banner collapsing to a menu-bar dot. Reuse, not invention: ◐ + warn-amber + the CONVENE? treatment are already in the system, so this reads as the roadmap's own signal surfaced proactively. Plain language (never "Epic #N" jargon) — names + the human gap ("designer-review open"). Trigger (mechanism = dev's): close-approach = the current iteration DRAINING toward done (members nearly all accepted — no time substrate; iterations close manually); not-ready = NEXT fails a convene-check (#1703); which-is-NEXT = the single-source order (#1735). The drain-gate maps to the far-horizon clause — a +3 can't fire.
