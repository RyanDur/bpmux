The urgency rides the pulse rate (slow→fast), not just hue — so it reads at a glance and color-blind-safe.

Live I/O modulation (any state)

Idle, receiving— brief dim = a message just flowed
Busy, chattering— flickers as it sends/receives

A subtle dim-flicker on each send/receive — a "communicating now" light, layered on the base color. It never changes the state-read; it just shows the agent is live.
