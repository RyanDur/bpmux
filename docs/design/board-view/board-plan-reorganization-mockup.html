The shape: top [Board | Plan] switcher (settled chrome). Board = the current iteration's gated lanes — the operational surface. Plan = the planning home, two sub-views: Roadmap (outcomes by Now/Next/Later — strategic) + Backlog (all epics + iterations + icebox — the ledger). Done tucks into Backlog, collapsed. The two altitudes — outcome (Roadmap) + story-ledger (Backlog) — sit under one Plan home; Board carries the in-flight work.

Designer taste-calls — react to any:
  1. Plan opens on Roadmap on first visit (the planning-entry glance), then persists the last sub-tab (useTabStorage, like today's tabs) — so the Roadmap-default only bites the very first open; a triage-heavy session stays on Backlog. (PM-validated: persistence is what makes the default low-stakes for both the owner-glance and the working-user.)
  2. Done = a collapsed disclosure at the bottom of Backlog (the ledger tail). Could be removed from Plan entirely if you truly never open it.
  3. Board has no sub-tab strip — the adaptive Board tab already names the iteration. (If a no-iteration state needs a fallback, that's the existing #1684 roadmap-fallback.)
  4. Top tab keeps 🗺 on "Plan" for map-metaphor continuity — trivial to drop to a bare "Plan".
