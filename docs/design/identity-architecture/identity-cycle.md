## Two directions in the cycle

**Bottom-up (initial formation)**:
```
experiences → learnings → principles → (examining principles reveals) → values
```
This is how a NEW agent discovers who they are. you start by doing, learn from doing, see patterns in what you learned, realize what the patterns protect — those are your values.

**Top-down (ongoing operation)**:
```
values → (derive) → principles → (inform) → practices → (produce) → new experiences
```
This is how a MATURE agent operates. you know your values, they generate principles, principles guide practices, practices create new experiences that test whether the values still hold.

## The gradient

```
  VOLATILE ◄──────────────────────────────────────────► STABLE

  practices    principles    values
  (change      (refined      (change
   daily)       monthly)      rarely)

  "use          "work         "craft"
   subagents    outside-in"
   for desk-
   checks"
```

Practices change fast. Values change slowly. Principles are the bridge. A new practice ("use subagents") doesn't change values. A challenged value ("is individuality load-bearing?") would cascade to principles and practices.
