lifecycle dots (8px, token colors): alive spawning spawn-failed exited (faded) — every state is visually distinct; blank-indistinguishable-from-working is designed out.

3-zone layout unchanged — only the center transforms

Sidebar (left) + board (right) stay positionally fixed. The terminal occupies the center column where chat goes — same principle as #1466. Terminals are user-created (new terminals section + +, one at a time, labelled N · cwd); the old click-a-role-to-attach path is gone, which deletes the #1466 fresh-blank-agent spawn entirely.

Start an agent = run a command

No special agent UI. cd then claude in the shell. "Watch" = native PTY output; "type/unblock" = native stdin. Both are free once the render is faithful.

Thin terminal header — label = spawn-dir (static)

The header/sidebar label is the spawn directory — stable identity (a label that renames itself every cd is a moving target). Live cols × rows · TERM stay (free, the load-bearing proof resize is real). Note: the shell's prompt already shows live cwd natively — so a header tracking cwd (iTerm tab-title feel, OSC-7, ~2pt) is a legit native-feel slice if wanted, not "polish"; scope call. Sidebar label stays static regardless.

Background-running + scrollback persists

Switching terminals doesn't kill the PTY; returning shows intact scrollback. The terminal owns its history — no bpmux message-history bleeds in.

Close/kill — the ＋ companion (S5)

✕ on the terminal's row (+ a close in the header) tears it down: SIGTERM→grace→SIGKILL, reap the process (no orphaned PTY leak), drop from the N-list. Confirm-before-close if a foreground process is running — don't silently kill a running agent. Closing the active terminal focuses the next one or an empty-state, never a blank center.

FALSIFIER resize-reflow

I'd reject if I resized the window and text still wrapped at 80 cols. FitAddon → PtyResize → winsize must reflow the live shell. (FitAddon is cosmetic-only today — this is the real work.)

FALSIFIER never-blank

I'd reject if a spawn that fails (or an exited shell) showed a blank pane indistinguishable from a working terminal. Each of spawning / failed / exited has a loud, distinct surface + dot.

FALSIFIER native fidelity (S1)

I'd reject if colors/cursor/TUI didn't render (must be xterm-256color, not plain log-tail), or if Ctrl-C didn't interrupt the live process, or scrollback / paste didn't work. (Paste + Ctrl-C ride the real shell free; Cmd-C copy is its own slice, S7.)

FALSIFIER copy fidelity (S7)

I'd reject if I selected terminal output and Cmd-C didn't copy it to paste elsewhere. Cmd-C bound ONLY — never Ctrl-C (that's SIGINT; binding it would be a bug).

FALSIFIER real shell powers

I'd reject if it weren't my login $SHELL with my env, or cd didn't actually change dir, or it spawned in the backend's cwd instead of a real working directory.

FALSIFIER close/kill (S5)

I'd reject if closing a terminal left its process running (orphan leak), the pane lingered, the N-list didn't update, or closing the active one dropped me to a blank center instead of the next terminal / empty-state.
